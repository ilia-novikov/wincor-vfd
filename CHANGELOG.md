# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-10-24

### Added

- REST API exposing display operations.
- Primitive authentication and health-check endpoints.
- OpenAPI schema for the REST API.

## [0.1.0] - 2026-10-24

### Added

- Basic driver implementation.
- Display operations: initialization, text printing and the rest of the display command set.
- `vfdctl` CLI exposing display operations as subcommands.
- Minimal test coverage.
- README.
